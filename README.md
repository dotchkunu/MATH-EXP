# 🐢 3D Turtle Graphics - Mathematical Expressions

A complete 3D Turtle Graphics implementation using Three.js with mathematical curve generation.

## 📋 Features

- 3D Turtle movement with pen up/down controls
- Mathematical curve generation (Spiral, Helix, Rose, Toroidal Spiral)
- Interactive camera controls (Orbit, Zoom, Pan)
- Real-time position display
- FPS counter
- Beautiful visual effects (fog, starfield, lighting)
